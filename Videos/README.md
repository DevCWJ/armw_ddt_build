# Videos 폴더 빌드 후 처리 안내

이 폴더(`Assets/!Media/Videos`)에 있는 모든 동영상 파일 및 하위 폴더들은 WebGL 빌드 시 빌드 결과물 폴더 최상단에 `Videos`라는 이름의 폴더로 자동 복사됩니다.

이 과정은 `VideoUrlPathHelper.cs` 파일에 정의된 `PostBuildVideosCopy` 스크립트에 의해 수행됩니다.

## 목적

WebGL 플랫폼에서는 `Application.dataPath` 경로에 직접 접근할 수 없으므로, 빌드된 프로젝트와 함께 동영상 파일들을 서버에 배포해야 합니다. 이 스크립트는 해당 과정을 자동화하여, 빌드 후 동영상 파일들이 정상적으로 재생될 수 있도록 보장합니다.

## 주의사항

- 이 폴더 구조를 임의로 변경하거나 스크립트(`VideoUrlPathHelper.cs`)를 수정할 경우, 빌드 과정에서 동영상 복사가 정상적으로 이루어지지 않을 수 있습니다.
- 새로운 동영상 파일은 이 폴더 내에 추가하기만 하면 빌드 시 자동으로 포함됩니다.
